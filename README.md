# Vihor

Autonomno vozilo na platformi JoyCar sa vlastitom upravljačkom pločom
(PIC24FJ64GA702), WiFi vezom prema računaru i okretnom kulom.
Projekat iz predmeta RE/MKS, 2026/27.

## Gdje je šta

- **Razvoj:** grana [`dev`](https://github.com/lukavidic/Vihor/tree/dev).
  Tu su dokumentacija, električna šema i test programi.
- **Dokumentacija:** [Wiki](https://github.com/lukavidic/Vihor/wiki)
- **Zadaci:** Vihor SCRUM Board (kartica Projects)

Grana `main` sadrži samo ovaj opis. Na nju se spajaju isključivo gotove verzije.
